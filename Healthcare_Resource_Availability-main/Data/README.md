# Data directory:
This folder contains the datasets used in this project.

# Files:
- `raw_data.csv` – The original dataset before any preprocessing.
- `cleaned_data.csv` – Processed dataset used for analysis and modeling.
- `train_data.csv` – Training dataset (70% split) used for model training.
- `val_data.csv` – Validation dataset (15% split) used for hyperparameter tuning.
- `test_data.csv` – Test dataset (15% split) used for final model evaluation.

# Data source:
The dataset is sourced from the World Bank, WHO. More details on data preprocessing can be found in the Notebooks folder.
